Matrix Node

Can you route the signal and save the grid?

It's basically a puzzle game where you're connecting nodes, but here's the catch - mess up one connection and the whole thing crashes.

How It Works

Step 1
Read the Grid
First, you'll need to figure out which power sources connect to which receivers - and you better do it fast before everything starts falling apart.
Step 2
Trace Your Path
Draw energy lines across the matrix, routing around dead nodes and splitting signals through relay points.
Step 3
Stabilize or Lose
Connect every target node before the corruption spreads — one unclosed loop and the whole grid goes dark.

Features

  • Procedural Grid Generation

    Every time you play, you get a completely different puzzle. We don't just shuffle the same layouts around - each grid is genuinely unique.

  • Node Type System

    Different node types like relays and amplifiers actually change how the energy flows, so the puzzles get trickier as you go.

  • Cascade Timer Mechanic

    The corruption literally spreads while you're playing - it's like racing against a virus that's eating your grid.

  • Deep Layer Unlocks

    As you progress, you'll unlock more complex grids where the rules start changing on you (in subtle ways that'll make you second-guess everything).

About

We made Matrix Node for people who like their puzzles challenging but fair - no tutorials holding your hand, just you vs. a grid that doesn't want to cooperate. Each puzzle has that one perfect solution hiding in there somewhere - you just have to find it. We built the framework - now it's up to you to make it work.
